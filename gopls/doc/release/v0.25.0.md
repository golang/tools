### `unusedfunc` analyzer also reports unused struct fields

The existing `unusedfunc` analyzer now additionally reports a
diagnostic for each unexported field of a named struct type that is
never referenced within its package. (An unkeyed struct literal
`T{x, y}` counts as an implicit use.)

## Model context protocol (MCP) features

<!-- golang/go#82392 -->
All MCP tools now set the `readOnlyHint` annotation, since none of
them modify the workspace. (`go_rename_symbol` returns the edits
as a diff for the client to apply.) Some clients that ask for
approval before running tools that are not read-only can now run
the gopls tools without prompting.
